# Sieve demo

The public demo of Sieve at https://sieve.junh.kim. Everything runs in the browser on sample pages and generated sample media; it never contacts another site.

Sample images and clips are original, generated for this demo. Fonts: Inter and Bricolage Grotesque, SIL Open Font License 1.1 (see `fonts/`).
